# Скиллы дизайна

Взяты из проекта **taste-skill** (github.com/Leonxlnx/taste-skill), лицензия MIT —
файл `LICENSE` рядом.

Установлены те, что применимы к этому сайту:

| Скилл | Для чего |
|---|---|
| `redesign-skill` | аудит существующего дизайна, поиск «generic AI»-паттернов |
| `taste-skill` | общий анти-шаблонный подход к фронтенду |
| `soft-skill` | «дорогая» подача: шрифты, отступы, тени, карточки |
| `minimalist-skill` | чистый редакционный минимализм |
| `brutalist-skill` | жёсткая сетка, крупная типографика (альтернативный стиль) |
| `output-skill` | запрет на обрезанный код и заглушки в ответе |

Не ставились: `imagegen-frontend-web/mobile`, `brandkit`, `image-to-code-skill`
(нужна генерация изображений), `gpt-tasteskill` (для GPT), `stitch-skill`
(для Google Stitch), `taste-skill-v1` (устаревшая версия).
