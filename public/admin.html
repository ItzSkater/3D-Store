🔔 Уведомления в Telegram

Получайте мгновенные уведомления о новых заказах и сообщениях прямо в Telegram.

Как настроить (2 минуты):
  1. В Telegram откройте @BotFather → команда /newbot → придумайте имя. Получите токен вида 123456:ABC....
  2. Напишите своему новому боту любое сообщение (например «привет»).
  3. Узнайте свой Chat ID: откройте бота @userinfobot — он пришлёт ваш ID (число).
  4. Вставьте токен и Chat ID ниже и сохраните.
